## 🚀 Как запустить прямо сейчас

```bash
# 1. Клонировать репозиторий
git clone https://github.com/rvk311096-rgb/- chromia

# 2. Перейти на нужную ветку
cd chromia
git checkout claude/color-palette-app-3f9u80

# 3. Установить и запустить
cd color-palette
chmod +x install.sh && ./install.sh

# 4. Запуск
./chromia.sh
# → Приложение откроется на http://localhost:3000
```

**Запуск в фоне (чтобы закрыть терминал):**
```bash
nohup ./chromia.sh &>/tmp/chromia.log &
# Остановить: pkill -f "vite"
```

## 💾 Ресурсы и память

### Размер приложения
| Компонент | Размер |
|---|---|
| JS бандл (gzip) | 178 kb → **57 kb** в сети |
| CSS (gzip) | 15 kb → **3.5 kb** в сети |
| node_modules | ~180 MB (только для разработки) |
| Исходный код | ~50 KB |

### Потребление памяти при работе
| Что | Сколько |
|---|---|
| Vite dev-сервер (Node.js) | ~80–120 MB RAM |
| Вкладка браузера | ~60–100 MB RAM |
| CPU в простое | <1% |
| CPU при смене цвета | 2–5% (пересчёт гармоний) |
| Сеть | 0 (всё локально, кроме шрифтов Google и Unsplash) |

### Сетевые запросы при старте
- `fonts.googleapis.com` — загрузка Space Grotesk + Space Mono (разово, затем кэш)
- `source.unsplash.com` — только при нажатии **Find Image**
- Всё остальное: **полностью офлайн**

## 🔒 Безопасность

### Что приложение делает
- Запускается **локально** на вашем компьютере
- Не отправляет никакие данные на внешние серверы
- Не собирает аналитику
- Не требует авторизации или аккаунта

### Внешние зависимости (только при запросе от пользователя)
| Сервис | Когда | Что передаётся |
|---|---|---|
| Google Fonts | при загрузке | только запрос шрифта |
| Unsplash | кнопка "Find Image" | поисковый запрос (текст) |

### Анализ зависимостей (npm)
| Пакет | Назначение | Безопасность |
|---|---|---|
| `react` 18.3 | UI фреймворк | ✅ Meta, широко используется |
| `vite` 5.4 | dev-сервер/бандлер | ✅ открытый исходный код |
| `react-colorful` | пикер цвета | ✅ без внешних запросов |
| `lucide-react` | иконки SVG | ✅ без зависимостей |
| `tinycolor2` | работа с цветом | ✅ нет сети |
| `framer-motion` | анимации | ✅ нет сети |

### Потенциальные риски: НИЗКИЕ
- Dev-сервер Vite слушает `localhost:3000` — **недоступен из интернета** по умолчанию
- Не используется `--host` флаг, значит порт закрыт для локальной сети
- Нет баз данных, нет хранения паролей, нет cookies с данными пользователя

### Рекомендации
```bash
# Убедиться что порт не открыт наружу:
lsof -i :3000
# Должно показывать только 127.0.0.1 (localhost), не 0.0.0.0
```

## 📋 Функции приложения

- **Color Picker** — визуальный выбор цвета + HEX ввод
- **Pantone® Names** — ближайший Pantone для любого цвета (~80 цветов в базе)
- **8 гармоний** — Complementary, Analogous, Triadic, Split-Complementary, Tetradic, Monochromatic, Pastel, Earth Tones
- **2–6 цветов** в палитре
- **3 режима** отображения: карточки / полоски / сетка
- **Форматы** — HEX, RGB, HSL, CMYK (с кнопкой копирования)
- **Random Palette** — случайная эстетичная комбинация
- **Find Image** — подбор изображения под палитру (Unsplash)
- **Export** — сохранение палитры в .txt
