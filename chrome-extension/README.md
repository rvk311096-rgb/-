# Dashboard Bookmarks — Chrome Extension

Кастомная страница новой вкладки с панелями закладок в стиле дашборда.

## Установка

1. Скачать/клонировать папку `chrome-extension`
2. Открыть Chrome → адресная строка → `chrome://extensions/`
3. Включить **"Режим разработчика"** (переключатель справа вверху)
4. Нажать **"Загрузить распакованное расширение"**
5. Выбрать папку `chrome-extension`
6. Открыть новую вкладку — увидите дашборд!

## Возможности

- 📌 Несколько панелей с цветными акцентами
- 🔗 Добавление/редактирование/удаление закладок
- 🔍 Поиск по всем панелям сразу
- 📊 Статистика в верхней части (количество панелей и ссылок)
- 🖱️ Правый клик на закладке — контекстное меню
- 💾 Данные сохраняются в localStorage (не теряются при перезагрузке)
- ✨ Тёмная тема в стиле дашборда
